## Gate (from DESIGN.md §11)

**Original (superseded):** measured on **every real image labelled in `fixtures/labels.csv`**. Targets: ≥ 90% **format** agreement on rows with a format; ≥ 85% **topic** agreement on rows with a topic (CLS-001.D5); every row tagged `suggestive-negative` must stay `safe`; the NSFW gate flags **every** labelled adult image and **0** safe ones; unrecognized < 10%. ## Privacy checklist (every task, front-loaded)

Every issue repeats this list. The Privacy auditor checks every item on round 1. It is the M2 lesson: #77, #81, #83 and #85 passed on round 1 once the list was given up front.

1. **Public repo.** Never put these in code, tests, recordings, commits, PRs, issues or journals:
   - image file names, captions, references or subjects;
   - host paths;
   - any value from `fixtures/labels.csv` or `sanitize.yaml`.

   **No aggregates** about the human's folder or fixtures either: counts, sizes, the type mix, label or category distributions, or per-category accuracy (DOC-005.D1). Real-fixture metrics are published only as TST-008.D1 allows.
2. **Logs, console, test output and errors** carry `short_hash` or `source_hash`. They never carry `source_path`, a raw or sanitized file name, a label value or a rule value.
3. **Models get pixels of the sanitized working copy only**, through `classifier/models/` (P-2). The source path and the raw name never reach a model.
4. **`repr=False`** on every field that holds a path, a name, a label row's values (`file`, `reference`, `subject`) or a rule value. That is pydantic `Field(repr=False)` or dataclass `field(repr=False)`, result types included. Each such type gets one repr/str test with planted synthetic secrets in each such field.
5. **Errors:**
   - raise outside the `except` block, from a precomputed fixed string, so `__cause__` and `__context__` are both None (test both);
   - never `str(exc)` of an OS, Pillow or library error, which embeds the path.
6. **Filesystem calls whose path may carry a name** are wrapped: `OSError` becomes fixed text, unchained. That covers `open`, `Image.open`, `resolve`, `is_file`, `stat`, `mkdir` and directory listings. Non-regular files and symlinks are refused wherever a read or write follows.
7. **Encodes use `surrogatepass`** (or reject cleanly), so a `UnicodeError` never quotes a character.
8. **Tests:**
   - synthetic images generated in code; never read `fixtures/` outside the `gpu` and `gate` tiers (TST-004);
   - synthetic names, places and category names are unmistakably artificial coinages (`Qorvex`, `Zhyndel`), never plausible real ones;
   - **never synthesise or describe adult content.** NSFW tests use benign synthetic images and replayed scores.
9. **Recordings** are keyed by hashes and made from synthetic inputs only (TST-005.D1, TST-008.D3).
10. **Write-ups** you post (PR bodies, commit messages, issue comments, job-log excerpts) carry hashes, test counts and pass/fail. Never a per-source or per-category split of a real-fixture result, and never anything about what the human's local files contain or lack.
