# Milestone 5 — Name: built-in and user templates, captions from both VLMs, collisions

<!-- Rules: CLAUDE.md §1 and "Milestone gates". Written by the lead at G0. Public repo: no image names, no captions of real images. -->

## Gate (from DESIGN.md §11)

"0 sensitive values in 500 names. A readability spot-check of names passes human review at G1." · measured by `scripts/gate_5.py` (`make gate-5`), plus the human's readability review at G1.

**How it is met (the human's answers 4 and 11).** The 500 names are **synthetic**, as gate 2's were: seeded sensitive values planted in synthetic source names and synthetic captions (recorded model answers), rendered through the real templates and the real name node. The gate passes when none of the seeded values survives in any name. The readability spot-check reads names from a real whole-folder dry run, on the box only, and the human passes or fails it by judgment.

## Scope

From DESIGN §4.4, §4.6 and §11:

- **R-CAP-1, R-CAP-2, R-CAP-3: the caption node.** The safe branch on `models.vlm_safe`, and the adult branch on `models.vlm_nsfw`. Each gives `{subject}` (1–3 words), `{detail}`, `{caption}` and `{tags}`, from a versioned prompt. The adult prompt asks for neutral, non-graphic descriptors, plus a character or franchise if recognizable.
- **R-NAME-1 to R-NAME-8: the naming.**
  - the six built-in templates, user templates from the CLI, assignable globally or per category, and `preview --sample N`;
  - the tokens and filters;
  - `{date}`, `{time}` and `{year}` from the kept EXIF date or the source mtime;
  - adult files on the category's own template, with the `nsfw_` prefix inside the 120-character cap;
  - normalization, then the sanitize rules re-run on the result (R-SAN-7);
  - collisions;
  - `{reference}` empty until M6, with an `|or=` fallback.
- **R-PIPE-2: the dry run reaches `proposed`.** That closes C-22's M3 deviation. The dry-run CSV carries the proposed name.
- **§5: `naming_templates` and `template_assignments`.**
- **§7:** `classifier templates {add,set-default,assign,preview}`, plus `list`, an extension of §7 that the human may add to DESIGN.
- **The human's answer 10:** the dashboard, the review queue and the report show the proposed name, read-only.

**Out of M5:** RAG, the judge and the web (M6), so `{reference}` stays empty; filing (M7), since the dry run only proposes; SAN-004; the UI's write actions (M8).

**Privacy (front-loaded; checklist items 16–20 below):** a caption is new model output about image content. It is stored in the ledger, and it can carry text that is visible in an image. So captions are sanitized on write (answer 6), and real people are never named (answer 7). Caption text and names of real images stay on the box; nothing public describes them.

## Privacy checklist (every task, front-loaded)

M3's items 1–10 and M4's items 11–15 apply unchanged. M5 adds:

16. **Captions are image content.** Never commit, post or log a caption, a subject, a tag or a name made from a real image. Tests and recordings use synthetic images and coined strings only (TST-005). Caption fields are `repr=False` everywhere.
17. **Sanitize on write:** every caption field passes the sanitize rules before the ledger (answer 6). A test plants seeded values in a recorded caption, shows the raw answer holds them, then asserts that the stored row, the logs and the reprs don't.
18. **No real people named (answer 7), and no transcribed visible text (answer 8).** The prompts say so, and sanitize-on-write's entity rule (PERSON, ORG, LOCATION) is the net for names the model writes anyway. A synthetic test image with printed coined text checks the net. The residual risk is a real person's name the entity rule misses. It stays box-only, and the human reads real captions at G1.
19. **Names:** the rendered name re-runs the sanitize rules (R-SAN-7). Neither the console nor the logs print a real proposed name; `templates preview` renders synthetic rows only (CLI-010.D1). Names reach only the local ledger, the local dry-run CSV, and the dashboard and report on 127.0.0.1.
20. **Public results:** gate 5 publishes a verdict and its own synthetic count only (TST-016.D1). The G1 readability sample stays on the box, and nothing public carries an example name or caption.
